Drag images here, paste screenshots with Ctrl + V, or use the file picker above.
Tip: for fully replicated images, leave Exact Copy Mode enabled. In the browser print dialog choose A4, Portrait, Scale 100%, and disable headers and footers. If your printer cannot print edge to edge, use Small margin instead of No margin.
"Exact size" mode lets you type the physical width and height (in mm) you want each printed picture to be, and the tool automatically works out how many fit on the page and arranges them. Turn on "Edge-to-edge" to remove the gap between pictures so there is less blank paper to trim after printing.
If the width/height you type don't match your picture's real proportions, Exact Copy Mode will add thin white bars inside each box to avoid cropping - with Edge-to-edge on, those bars from neighbouring pictures add up into a visible white band between them. "Auto-match picture's proportions" keeps the height in sync with the width using your first picture's actual shape, so each box exactly fits the picture with no bars. Turn it off if you want to crop the picture to your own exact size instead (use "Fill cell and crop edges" and turn off Exact Copy Mode for that).
